# FORME — DEMO / Concept

Локальный демонстрационный лендинг вымышленного бренда сумок и аксессуаров. React + Vite, JavaScript, обычный CSS. Без backend, оплаты, форм сбора персональных данных и API.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Открыть адрес, который выводит Vite. По умолчанию: http://127.0.0.1:5173/.

```powershell
npm run build
npm run preview
```

## Что работает

- Навигация по секциям, мобильное меню, закрытие меню клавишей Escape.
- Фильтры по категориям и показ избранного, включая пустое состояние.
- Добавление и удаление из избранного, счётчик и статус для скринридера. Состояние хранится в памяти, до перезагрузки.
- Просмотр модели в нативном модальном `dialog`, удержание фокуса и закрытие по Escape.
- Контактное окно честно объясняет демонстрационный статус. Ничего не отправляется.
- Skip-link, видимый фокус, семантические секции, альтернативные тексты, reduced-motion.

## Браузерная проверка и PNG

В другом терминале при работающем сервере:

```powershell
npx playwright install chromium
npm run test:portfolio
```

Если системный кэш Chromium повреждён, можно использовать отдельный экземпляр:

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH="$PWD/.browsers"
npx playwright install chromium --only-shell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE="$PWD/.browsers/chromium_headless_shell-1248/chrome-headless-shell-win64/chrome-headless-shell.exe"
npm run test:portfolio
```

Номер папки зависит от установленной версии Playwright; актуальный путь показывает установка. `PREVIEW_URL` позволяет проверить `npm run preview` вместо dev-сервера.

Скрипт делает настоящие скриншоты, проверяет изображения, горизонтальную прокрутку, фильтры, избранное, модальные окна, мобильное меню и axe WCAG 2.1 AA. Результаты: `../portfolio/qa/browser-report.json`. PNG: `../portfolio/screenshots/`.

## Контент и права

Источники фотографий и лицензия указаны в `public/credits.html`. Фотографии — референсы для концепции, не реальные товары FORME. Pocket — оригинальная локальная SVG-иллюстрация. Фотографии и иконки загружаются локально. Системные шрифты не требуют подключения внешних сервисов. Цены условные. Клиенты, отзывы и коммерческие результаты не заявляются.

REST API не используется и не заявляется как реализованная функция.
